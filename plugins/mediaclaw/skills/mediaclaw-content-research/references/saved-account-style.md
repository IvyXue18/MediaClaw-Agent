# 已保存账号风格适配方法

- Method ID: `saved-style-adaptation-v1`
- Version: `1.0.0`
- Tool: `mediaclaw_list_assets` + `mediaclaw_get_asset`
- Kind: generation modifier

## 读取条件

- 先查 `local.studio` 的 `style_profile` / `account_analysis`；用户需要云端历史时再查 `remote.workbench`。
- 必须使用列表返回的稳定 `assetId` 调用 `mediaclaw_get_asset` 后，才能使用风格。
- 多个候选时根据账号名、平台、主页链接、样本量和更新时间消除歧义；仍不确定时请用户确认。
- 没有真实资产时明确说明，不根据账号名或印象猜测。
- `effectiveAnalysisSource` 为 `editableJson` 时，优先使用用户编辑后的分析；否则使用 `profileJson`。

## 风格解码

不要把完整 `styleAnalysis` 直接塞进成稿。先提炼为五层风格控制器：

1. **立场**：作者通常从什么身份和判断位置说话。
2. **结构**：如何开场、展开、证明、转折和收束。
3. **节奏**：句长、段长、信息密度和停顿。
4. **措辞**：口语程度、常见句式、修辞和禁用表达。
5. **包装**：标题、封面、标签和 CTA 偏好。

将每项分成：

- 必须保留的稳定规则。
- 可选的表达偏好。
- 只属于样本内容、不得迁移的身份事实和独特素材。

## 适配顺序

优先级不可颠倒：

1. 用户提供的事实、观点和身份。
2. 当前内容任务书的目标、受众和证明。
3. 风格档案中的稳定表达规则。
4. Agent 的一般可读性优化。

风格冲突时保留更高优先级内容。

## 生成规则

- 模仿结构选择和语言节奏，不逐句仿写。
- 不移植样本账号的经历、成绩、客户、产品效果或身份。
- 不复用样本中的独特句子和连续表达。
- 不为了“像”而加入用户不会说的立场。
- 先生成符合事实的版本，再做风格化；风格化后重新执行质量闸门。

## 交付

简短说明使用了哪个已保存账号档案。无需展示完整风格 JSON，也不要宣称与原账号完全一致。
