# 证据驱动选题方法

- Method ID: `evidence-topic-ideation-v1`
- Version: `1.0.0`
- Kind: generation

## 目标

把研究结论转化成少量真正不同、能够制作、能够证明的选题。不要根据热点标题批量改写同义句。

## 必需输入

- 用户目标：平台、受众、账号定位或商业目标；缺失时使用对话中可确定的信息。
- 至少一个 TRACE 分析结论。
- 可引用的需求、样本或评论证据。
- 用户能够提供的真实经验、案例、过程或素材；未知时明确标为待补。

## 选题生成步骤

1. 从分析中选择 2～4 个优先机会，不从全量热门样本直接生成。
2. 为每个机会写出：
   - 目标读者
   - 触发场景
   - 核心矛盾
   - 已有内容的常见回答
   - 用户可以提供的新角度或新证明
3. 使用以下一种差异来源生成候选：
   - 新对象：为更具体的人群重写问题。
   - 新场景：切到决策、执行或复盘中的具体时刻。
   - 新判断：提出有证据支持的反常识或边界。
   - 新证明：用过程、对比、实测、案例或失败复盘增强可信度。
   - 新结构：把宽泛议题改成清单、决策树、教程或实验。
4. 删除无法提供真实证明、只靠夸张承诺或与用户资源不匹配的候选。
5. 保留 3～5 个差异足够大的优先选题。

## 选题卡输出契约

每个选题必须包含：

```text
选题：
目标读者：
触发场景：
核心矛盾：
新角度：
内容承诺：
需要的证明素材：
推荐形式：
证据来源：
风险或待验证点：
```

标题不是选题。用户需要标题时，为每个选题提供 2～3 个不同承诺强度的标题，并确保正文能够兑现。

## 质量标准

- 选题之间不能只替换关键词。
- 至少一个证据来源支撑每个选题。
- 必须说明用户凭什么能写，而不只是市场为什么想看。
- 不因为样本高赞就默认用户适合复制。
- 通过 [内容质量闸门](content-quality-gate.md) 后再交付。
