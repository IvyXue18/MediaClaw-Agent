# 关键词选题趋势方法

- Method ID: `keyword-topic-trends-v1`
- Version: `2.0.0`
- Tool: `mediaclaw_capture_search_basic`，需要正文机制证据时再用 `mediaclaw_enhance_records`

## 目标

判断一个关键词下有哪些稳定需求、近期变化、拥挤方向和可执行机会。不要把点赞榜改写成趋势报告。

## 默认证据

- 平台：用户指定，否则小红书。
- 时间范围：最近半年。
- 排序：最多点赞。
- 内容类型：全部。
- 搜索范围、位置距离或视频时长：全部不限。
- 列表扫描：80 条。
- 基础列表不自动打开详情页。
- 详情增强只在需要解释机制或提高置信度时，对最小充分样本执行。

用户明确指定的时间、类型、数量或排序优先。

## 基础列表分析

只有列表证据时：

1. 检查实际样本量、筛选执行情况和缺失字段。
2. 按“人群 × 场景 × 任务”归纳 4～7 个互斥需求方向。
3. 比较各方向的样本数、中位表现、峰值和近期样本，不以最高赞代替稳定性。
4. 标出历史峰值、近期出现、长期重复和证据不足的方向。
5. 给出方向级结论和初步选题，不解释尚未深采的正文、视觉或叙事机制。

## 详情增强分析

出现以下任一情况时，从当前数据池选择高表现、典型、反例、近期和不同形式的最小充分样本，说明范围并取得确认后调用 `mediaclaw_enhance_records`：

- 用户要求解释内容为什么有效。
- 需要比较标题、正文、视觉、证明或互动机制。
- 主要方向只有单篇峰值，无法判断是否可重复。
- 已有详情证据之间存在冲突。

样本覆盖高表现、中等表现、低表现、近期内容和不同形式。深采后：

1. 用 TRACE 的 Audience tension 还原每个方向的人群、场景、矛盾、承诺与行动。
2. 比较同一方向高低表现样本的入口、承诺、证明和形式差异。
3. 将结论分为赛道常量、表现放大器、偶发素材和待验证假设。
4. 用需求明确度、重复证据、差异空间、证明素材和用户匹配度排序机会。

## 输出契约

1. 一句话趋势判断。
2. 数据覆盖、证据等级和限制。
3. 4～7 个需求方向，每个包含：
   - 目标人群与场景
   - 样本分布和表现特征
   - 代表证据
   - 当前置信度
4. 历史峰值、近期变化和反例。
5. 拥挤方向、机会方向和待验证方向。
6. 用户需要选题时，进入 [证据驱动选题方法](topic-ideation.md)。

## 禁止

- 不得根据单篇最高赞推断整体趋势。
- 点赞量是表现信号，不等于质量、转化或因果。
- 未成功应用时间或排序筛选时，不得声称是严格半年趋势或点赞榜。
- 没有详情证据时，不得推断完整叙事、视觉系统或评论机制。
