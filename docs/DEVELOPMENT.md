## 发布门槛

只有同时满足以下条件，README 才能去掉“技术预览”：

1. GitHub 安装不要求普通用户手工配置 MCP、端口或令牌。
2. 首次连接与重连有明确状态，秒级成功或返回可操作错误。
3. 每个宿主独立显示、配对和撤销。
4. 免费与会员权限和浏览器插件完全一致。
5. 小红书、抖音的单条、基础批量、增强、评论、OCR、逐字稿验收通过。
6. 多宿主并发不会串任务、串结果或绕过确认。

## 仓库同步策略

从本仓库建立首个可验证基线后，Agent 接入代码以本仓库为唯一源码。浏览器插件主仓库只保留协议兼容测试和发布版本引用，不再维护另一份可独立修改的副本，避免两个仓库长期漂移。
